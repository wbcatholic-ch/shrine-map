# 가톨릭길동무 V1762 — 기존 앱 내 개발자 시험용 순례 지도

- 신규 앱/APK를 만드는 것이 아니라 기존 가톨릭길동무의 개발자 도구 안에서 시험합니다.
- 진입: 설정 → 앱 버전 10회 탭 → 개발자 도구 → **신규 순례 지도 V2 시험** ON.
- 안전 기본값 OFF. 페이지 새로고침/앱 재실행/개발자 모드 해제 시 자동 OFF. 개발자 모드와 시험 스위치를 모두 켜야 새 지도에 진입합니다.
- 개발자가 OFF로 두면 기존 순례 지도, 일반 성지·성당·피정 지도와 길찾기를 그대로 사용합니다.
- 현재 코드상 테스트 대상: 순례완료·순례계획의 지도에서 추가, 계획 세우기의 지도에서 추가, 코스 보기, 장소 정보의 지도에서 보기.
- 완료 코스 GPS 기록은 수정 불가, 별도 수동 경유지에만 저장 가능한 기존 규칙 유지.
- 개발자 모드의 실제 편집은 **기기 내 기존 순례계획/완료의 수동 기록을 변경할 수 있습니다.** 사전 백업 필요.
- 테스트 중 발견한 결함: 경유지 편집 취소/다시 실행 기능 추가, 경유지 한도 초과 시 신 지도로 우회하지 않음.
- 정적 JavaScript 문법 검사와 Node 모의 검사는 통과했으나 실제 카카오 지도·REST 경로·폴드·Android Back·네트워크는 미검증. 실사용 전 테스트 필요.
- 현재 웹 소스만 수정했습니다. Android 소스, 앱 아이콘, 운영 배포는 수정하지 않았습니다.
