미사/기도문 진행중 순례 복귀 버튼 위치 정리

1. 표시 조건
- 진행 중인 순례가 있을 때만 보임
- active follow가 없으면 버튼과 floating layer 모두 완전히 숨김

2. 위치
- 미사/기도문 헤더 안에서 버튼 제거
- 별도의 독립 floating layer로 이동
- 화면 우측 상단과 중앙 사이 지점에 고정
- 헤더/굿뉴스 버튼/X 배치에 영향 없음

3. 크기
- 기존보다 조금 크게:
  · min-width 122px
  · min-height 42px
  · font 14px
  · 좌우 padding 16px
- 작은 화면에서도 116x40px 이상 유지

4. 기존 기능
- 누르면 진행 중인 순례하기 화면으로 복귀
- 미사/기도문 예외 복귀 규칙은 그대로 유지
