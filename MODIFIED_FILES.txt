길찾기 / 순례 지도 CSS 중복 정리

삭제·통합한 부분
- 순례코스 보기 / 다음 순례지 길찾기 결과 화면을 여러 번 반복 지정하던 CSS 블록 제거
- 순례 전용 oai-pilgrimage-route-context에서
  left / right / width / padding을 따로 덮어쓰던 규칙 전체 제거
- 순례코스 보기 전용 결과 CSS 중복 블록 제거
- 동일 기능은 하나의 '순례 길찾기 UI 통합 규칙'으로 합침

핵심 변경
- 성지 / 성당 / 피정 / 지도에서 추가 / 순례코스 보기 / 다음 순례지 길찾기의
  입력창 가로 시작점과 폭은 모두 공통 #sheet-route CSS만 사용
- 순례 전용 CSS는 더 이상 입력창의 좌우 위치를 변경하지 않음
- 순례 전용 CSS는 보기 전용 표시/숨김, 요약 구조, 결과판 표시만 담당

- 지도 중심 보정
- 거리/시간/카카오내비
- 지도에서 추가 편집 기능
- 다음 순례지 길찾기 자동 재시도
