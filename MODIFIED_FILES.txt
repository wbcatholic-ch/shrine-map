V8-1-14-988

남아 있던 3가지 수정사항 일괄 반영

1. 순례지 녹색선
- 1번부터 모든 순례지 행에 표시
- 출발지 파란선 / 도착지 빨간선과 같은 X 위치, 같은 7px 두께
- 행 사이에서 이어지지 않는 개별 녹색 세로선
- 다음 순례지는 녹색선 유지 + 노란 배경/상하선만 강조

2. 지도에서 추가 후 새 장소 반영
- 앱 DB 등록 장소는 기존 데이터와 매칭
- 앱 DB에 없는 장소도 사용자가 경유지로 추가했다면 이름/주소/좌표 그대로 순례코스에 포함
- 등록되지 않은 장소는 코스에는 포함되지만 GPS 축하 팝업 규칙은 기존대로 유지
- 지도에서 추가/삭제/순서변경 후 순례하기로 돌아오면 현재 저장 코스와 활성 순례에 즉시 동기화

3. 내 위치에서 다시 거리 계산
- 버튼을 누른 순간 새로 받은 GPS 위치를 시작점으로 사용
- 각 순례지 누적 거리/시간을 현재 위치 기준으로 다시 계산
- 총 이동 거리 / 예상 시간도 같은 현재 위치 기준으로 함께 다시 계산
- GPS 방문등록 확인은 기존대로 함께 수행
