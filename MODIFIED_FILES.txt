기능 수정
- 순례계획의 지도 관련 버튼 문구를 모두 "지도에서 추가"로 통일
- 순례계획의 모든 "지도에서 추가" 진입을 하나의 공통 지도 화면으로 통합
- 공통 지도 화면의 줌 레벨, 성지 마커 색상, 성당 마커 미표시, 마커 클릭 선택창을 완전히 동일하게 적용
- 진입 위치만 다르게 적용: 일반 지도에서 추가는 마지막 순례지→도착지→출발지→현위치, 출발지/도착지에서 들어오면 해당 입력 장소→현위치
- 지도 이동 때마다 마커를 삭제·재생성하던 idle 갱신 제거
- 성지 데이터만 한 번 로드하고 약 188개 성지 마커를 한 번만 생성하도록 최적화
- 지도에서 추가 진입 시 기존 성지/성당/피정/지역검색 마커를 숨겨 중복 렌더링과 버벅임 감소
- 성당 데이터 로드를 지도에서 추가 흐름에서 제거하여 진입 속도 개선
