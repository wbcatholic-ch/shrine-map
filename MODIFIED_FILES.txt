기능 수정
- 저장된 순례계획에 실제 순례 완료 이력을 기록하도록 추가
- 코스의 모든 순례지가 완료되면 완료 시각과 완료 순례지 수를 해당 코스 기록에 저장
- 출발지·도착지는 완료 판정에 포함하지 않고 순례지 목록만 완료 대상으로 유지
- 성지순례 계획 목록 카드에 작은 '✓ 순례완료' 스탬프와 최근 완료 날짜 표시
- 같은 코스를 여러 번 완료한 경우 완료 횟수 표시
- 완료된 코스 카드에 '다시 순례' 버튼 추가
- '다시 순례'를 누르면 기존 완료 이력은 보존하고 순례지 완료 상태만 초기화하여 같은 코스를 다시 진행
- 완료 직후 완료취소/재완료로 중복 완료 기록이 생기지 않도록 1회 순례 단위 완료 잠금 추가
