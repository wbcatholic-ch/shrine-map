V8-1-14-990

이번 수정은 1, 2번 + 카카오내비 중앙 정렬만 반영

1. 순례지 녹색선
- 기존 각 행의 끊긴 녹색 막대 제거
- 순례지 목록 왼쪽에 하나의 연결된 녹색 세로선으로 표시
- 출발지 파란선 / 도착지 빨간선과 같은 X 위치, 같은 7px 두께
- 녹색선 때문에 순례지 번호/이름 전체가 오른쪽으로 밀리던 현상 제거
- 순례지 내용 위치를 기존 균형으로 복원
- 다음 순례지는 녹색선 유지 + 노란 배경/상하선만 강조

2. 순례완료의 '다음 순례지 길찾기'
- JS에서 hidden 처리되어도 기존 display:block!important가 다시 표시시키던 CSS 충돌 수정
- 순례완료에서는 '다음 순례지 길찾기'가 확실히 숨겨짐

추가
- 길찾기 결과의 카카오내비 버튼 아이콘/문구를 가로 중앙 정렬

3~8번 기존 수정은 건드리지 않고 그대로 유지
