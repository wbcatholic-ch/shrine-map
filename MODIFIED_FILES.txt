V8-1-14-1003

1. 순례하기 → 지도 이동 시 지도 중심 보정
- 하단 route 카드가 열려 있으면 지도 전체 화면 중앙이 아니라
  '하단 카드에 가려지지 않은 실제 지도 영역'의 중앙으로 지점을 이동
- 적용:
  · 지도에서 추가
  · 순례코스 보기
  · 다음 순례지 길찾기
- 하단 카드 높이가 정해진 뒤 120ms / 320ms에 다시 한 번 보정하여
  카드 높이가 바뀌어도 중심이 가려진 쪽으로 내려가지 않음
- Fold 큰 화면은 좌측 패널 방식이므로 기존 중심 방식 유지

2. 지도에서 추가 입력창 좌우 정렬
- 순례에서 들어온 길찾기 하단 카드에만 좌우 8px 동일 여백 적용
- left/right inset 방식만 사용
- transform / open 애니메이션은 건드리지 않아 기존 지도에서 추가 동작 유지
- 내부 출발/경유/도착 입력 영역과 결과 영역의 width/box-sizing 기준 통일

3. 기존 기능 유지
- V1002의 중복 패치 정리
- 순례코스 보기 요약 구조
- 다음 순례지 길찾기 자동 재시도
- 한 코스만 진행 / 다른 코스 시작 시 종료 확인
- 설정/개발자 모드 최소 보정
