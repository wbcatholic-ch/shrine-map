V8-1-14-999

순례하기 / 순례완료 순례지 행 레이아웃 복구

1. 순례지 행 구조 통일
- 진행 중 화면과 순례완료 화면 모두
  '드래그 표시 / 번호 / 성지명·거리'의 동일한 3열 구조 사용
- 번호, 성지명, 거리 정보가 서로 겹치거나 좌우로 쏠리는 문제 수정
- 긴 성지명은 정상적으로 말줄임 처리

2. 순례완료
- 기본 행 구조는 진행 중 화면과 동일
- '✓ 순례완료' 배지만 성지명 오른쪽 보조 위치에 표시
- 다음 순례지용 여백이나 라벨은 전혀 사용하지 않음

3. 다음 순례지
- 실제 다음 순례지 한 행만 노란 강조 유지
- '다음 / 순례지' 라벨은 기존 3열 구조를 변경하지 않고
  오른쪽에 독립적으로 표시
- 라벨 공간만 해당 행에 확보하여 성지명과 겹치지 않도록 수정

4. 이전 기능 유지
- V998의 다음 순례지 길찾기 첫 클릭 안정화
- 한 코스만 순례 진행
- 다른 코스 시작 시 기존 코스 종료 확인창
- 백그라운드 복귀 및 미사/기도문 예외
