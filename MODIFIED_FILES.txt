순례계획 완료 기록 / GPS 보호 / 순례 중 위치확인 개선
- 순례계획 목록의 년/월/구분 선택창을 모바일에서도 한 줄 3칸으로 통일
- 기본 표시를 년 / 월 / 전체로 단순화
- 완료 코스 카드의 붉은 반투명 순례 워터마크를 더 또렷하게 조정
- 같은 코스는 동일 날짜에 완료 기록이 두 번 생성되지 않도록 방지
- GPS로 전체 순례 완료된 기록은 완료 날짜 수정/삭제 금지
- GPS 완료 기록이 있는 코스는 코스 삭제 금지
- 기존 같은 날짜 수동 기록이 있어도 GPS 완주가 확인되면 해당 날짜를 GPS 보호 기록으로 승격
- 등록된 성지/성당이 출발지 또는 도착지일 경우 해당 위치 도착 시 GPS 방문/순례 등록 확인
- 순례하기 상세 화면에 '내 위치 확인' 버튼 추가
- 내 위치 확인 시 순례지 GPS 등록과 출발/도착 성지·성당 GPS 등록을 함께 확인
- 출발지/도착지 박스 경계를 심플 디자인을 유지하면서 조금 더 진하게 조정
