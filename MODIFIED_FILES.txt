첫 설치 초기설정 흐름 변경

1. 처음 실행
- 가장 먼저 'Google Drive에 연결할까요?' 표시
- 버튼은 'Google Drive 연결하기'

2. Google Drive 연결 후
- 자동 보관 ON
- 기존 Drive 백업을 먼저 확인

3. 기존 데이터가 있으면
- 별도 '가져오기' 버튼 없이 자동으로 복원
- '기존 기록을 가져왔습니다 / 데이터 가져오기가 완료되었습니다' 표시
- 확인하면 초기설정 완료

4. 기존 데이터가 없으면
- 바로 '나의 교구·본당 설정'으로 이동
- 교구 선택 후 본당 선택 화면으로 이어짐

5. Google Drive를 나중에 연결하면
- 경고 확인 후 교구·본당 설정으로 진행

보호
- 빈 로컬 기록을 Drive에 먼저 올리지 않고 기존 Drive 기록부터 확인
- 기존 데이터 복원 후 자동 보관 유지
