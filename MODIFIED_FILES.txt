날짜 연도 이동 / 선택 마커 재클릭 수정

1. 앱의 모든 날짜등록
- 모든 input[type=date]에 이전 년도/다음 년도 버튼 자동 추가
- 정적 날짜 입력과 동적으로 생성되는 날짜 입력 모두 적용
- 2월 29일 등 존재하지 않는 날짜는 해당 연도의 마지막 유효 날짜로 보정
- 기존 날짜 선택 달력은 그대로 사용 가능

2. 지도 선택 마커 재클릭
- 성당 선택 후 노란 선택 마커를 다시 눌러도 클릭 동작 유지
- 피정 선택 후 노란 선택 마커를 다시 눌러도 클릭 동작 유지
- 순례 지도 장소 선택 모드에서는 재클릭도 동일한 장소 선택 흐름으로 처리
- 성지는 기존 마커 객체의 이미지만 변경하므로 기존 클릭 리스너 유지
