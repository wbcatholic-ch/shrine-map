기능 수정
- 경유지 4곳부터 길찾기 입력 카드 높이를 더 이상 키우지 않고, 출발지·경유지·도착지와 경로 검색/+경유지 버튼까지 하나의 입력 영역으로 함께 스크롤
- +경유지를 누르거나 새 경유지를 지정하면 입력 영역을 자동으로 맨 아래로 이동해 마지막에 추가된 경유지와 버튼이 바로 보이도록 수정
- 입력 중 숨겨진 결과 영역(rs-bottom)이 여백을 차지하던 문제를 제거하고, 결과 화면 하단 여백도 실제 안전영역 수준으로 축소
- 순례계획 출발지/도착지 선택창의 버튼 문구를 '지도에서 변경'으로 변경
- 출발지/도착지의 지도에서 변경 화면은 일반 지도에서 추가보다 더 확대된 줌으로 표시
- 순례계획의 '지도에서 추가'는 기존과 동일하게 길찾기 편집 기능(출발지·도착지·최대 10개 경유지·경로검색·순례계획 수정)을 사용
