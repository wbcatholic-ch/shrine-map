1. 순례코스 보기
- 편집용 경유지 개별 목록을 숨김
- 출발지 / 경유지 N곳 요약 / 도착지 3줄 구조로 고정
- 경유지 입력 완료 후 즉시 결과 모드로 전환
- 도로 거리 / 소요시간 / 카카오내비 결과판 자동 표시
- 삭제 / 순서변경 / +경유지 / 경로검색은 계속 숨김

2. 지도에서 추가
- 휴대폰/접힌 화면에서 길찾기 편집 시트를 좌우 8px 동일 여백으로 중앙 정렬
- 왼쪽으로 치우쳐 보이던 현상 수정
- Fold 큰 화면 좌측 패널 구조는 변경하지 않음

3. 기존 기능 유지
- V999 순례지 행 정렬
- 다음 순례지 라벨
- 다음 순례지 길찾기 첫 진입 안정화
- 한 코스만 진행 / 다른 코스 시작 시 종료 확인
